The 10 K scan has usable EXAFS only to about **k = 14.6 Å⁻¹**, so I limited the Fourier transform to **k = 3–14.6 Å⁻¹** using the existing Hanning window and k² weighting.

The first-shell peak appears at **R ≈ 2.27 Å in the phase-uncorrected Fourier transform**. For Cu–Cu scattering, the corresponding physical bond distance is expected to be somewhat larger after phase correction.
