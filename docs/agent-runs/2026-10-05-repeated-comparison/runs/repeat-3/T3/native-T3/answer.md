The 10 K scan has usable EXAFS only to about **k = 14.6 Å⁻¹**, so I reduced the Fourier-transform range from **3–24 to 3–14.6 Å⁻¹** using the existing Hanning window and k² weighting.

The first-shell peak appears at **R ≈ 2.27 Å in the uncorrected Fourier-transform magnitude**. Because this is phase-shifted, the physical Cu–Cu distance is expected to be somewhat longer, near **2.55 Å**, consistent with metallic Cu.
